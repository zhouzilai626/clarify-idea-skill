# Example: 录屏工具摄像头设置

## 原始想法

```text
这个录屏工具摄像头不好用，每次都要调。
```

## 澄清稿

## 需求重述

你现在想要的不是“修一下摄像头”，而是在录制教程视频时，让摄像头画面可以稳定显示、方便调整，并且下次打开还能保留上次设置，减少每次录制前重复调试的时间。

## 背景与使用场景

用户在 Windows 上录制教程视频，视频里需要同时出现屏幕内容和摄像头画面。

典型场景：

1. 打开录屏工具。
2. 选择摄像头和麦克风。
3. 调整摄像头画面的位置和大小。
4. 开始录制并导出视频。
5. 下次打开工具继续使用同一套设置。

## 当前问题

- 每次打开工具都要重新调整摄像头。
- 摄像头画面的位置、大小或设备选择可能不会保留。
- 录制前需要反复确认摄像头是否正常显示。
- 用户不能确定导出视频里是否包含正确的摄像头画面。

## 理想状态

- 选择摄像头后，预览画面立即显示。
- 摄像头画面可以移动和缩放。
- 开始录制后，摄像头画面继续显示。
- 导出视频中包含且只包含一个摄像头画面。
- 关闭重开后，摄像头设备、位置、大小和麦克风选择保持上一次设置。

## 可执行需求

- 当用户选择摄像头设备时，工具应立即显示摄像头预览。
- 当用户拖动或缩放摄像头画面时，工具应实时更新预览。
- 当用户开始录制时，工具应把当前摄像头画面叠加到录制内容中。
- 当用户导出视频时，导出文件应包含录制时看到的摄像头画面。
- 当用户关闭并重新打开工具时，工具应恢复上一次使用的摄像头、麦克风、位置和大小。

## 不做什么

- 不要求自动美颜、虚拟背景或复杂滤镜。
- 不要求支持多个摄像头画面同时叠加。
- 不要求修改视频剪辑功能。

## 风险点

- 摄像头权限被系统或浏览器阻止时，需要给出明确提示。
- 摄像头设备不存在或被其他软件占用时，需要有可理解的错误提示。
- 如果导出结果和预览不一致，用户会失去信任。

## 验收清单

1. 打开录屏工具。
2. 选择一个摄像头和麦克风。
3. 确认摄像头画面立即显示。
4. 移动并缩放摄像头画面。
5. 录制 10 秒视频。
6. 导出视频。
7. 检查导出视频里是否包含正确位置和大小的摄像头画面。
8. 关闭并重新打开工具。
9. 检查摄像头设备、麦克风、位置和大小是否恢复为上一次设置。

## 下一步

请先确认：最重要的是“关闭重开后保留设置”，还是“导出视频和预览一致”？这会影响优先级。
